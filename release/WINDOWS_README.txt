利仓上位机 — Windows 64 位便携版

0.1.2 / 2026-11-10：登记本地编辑、一次保存；设备管理、串口设置、探头登记独立。
建议配合分机 V0.4，按实际登记点分页读取，1个探头无需读取170个槽位。
V0.3仍可用，但非空表会回退旧逐点读取。保留2C编码兼容及CRC/全0/全FF校验。
串口默认1200 / 8N1，当前单支路自动选择。更新软件无需清空数据库。
登记时修改用途、编号、绑定仅影响本地草稿，点击“保存到分机”后核对生效。
保存失败或不确定时按提示重新读取核对，不能把未确认结果当作成功。

1. 将 ZIP 完整解压到本地文件夹。不要在压缩包中直接运行，也不要只复制 EXE。
2. 双击 WarehouseTemperatureConsole.exe 启动正常模式。客户电脑无需安装 Python。
3. 无设备时可双击 Demo.cmd 体验模拟演示；模拟数据与正常数据分别存储。
4. 首次使用：新增分机（引导创建仓房/串口）→ 登记探头 → 保存到分机 → 关闭登记 → 开始采集。
5. 默认数据存放在当前用户的本地应用数据目录，可在“系统维护 → 本地维护”中查看。
   更新软件前请做数据库备份；软件文件夹和数据库是分开的。
6. USB 串口驱动需要按照实际适配器型号安装；串口参数必须与分机固件一致。

目标环境：Windows 11 x64（Intel / AMD 64 位）。
此包未做代码签名。运行时依赖的 _internal 目录必须保留。
build-info.json 记录此包的构建及测试结果，build-requirements.txt 记录构建依赖。
自动启动检查使用模拟设备，实际串口、探头、声音和屏幕缩放仍需在目标电脑验收。
