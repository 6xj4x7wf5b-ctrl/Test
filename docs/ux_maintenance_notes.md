# 参数、历史与维护

- **参数设置**。采集周期与历史保存间隔适用于全部分机。微调与阈值按所选分机配置，各栏在读取成功后才能编辑。切换分机或正在编辑的测点时，可以取消切换以保留输入。批量微调会先列出受影响的测点数，确认后保存。已核对绑定的分机只列出已登记测点，微调仅对之后采集的数据生效。
- **历史曲线与记录**。曲线入口展示单测点趋势，记录入口展示分页列表，两者共用查询条件。修改条件后点击“查询”才应用。CSV 和 Excel 导出最近完成查询的全部筛选范围，已有目标文件会再次询问是否覆盖。
- **历史清理**。选择分机和时间范围后先预览条数，预览期间继续采集。确认后短暂停止新增轮询，并在删除时复核同一范围的条数。若条数有变化，先重新预览。清理仅删除采集记录，档案、设置、报警记录及已有备份仍可使用。可先用“备份完整数据库”留存副本。
- **通信诊断**。本地维护页可将当前端口参数、连接状态和本次运行最近的通信事件导出为 JSON，便于排查无应答和报文错误。
