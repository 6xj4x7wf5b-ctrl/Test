# 上位机 0.1.2 / 分机 V0.4 优化说明

本次在旧项目上继续修改；修改前完整备份位于项目 `backups/ux_optimization_before_20261110_132807`。

## 日常操作

1. 设备管理 → 测温分机管理 → 新增分机。没有仓房或串口时会引导创建，串口默认 1200 / 8N1。
2. 选择分机 → 登记探头（或进入独立“探头登记”页面）→ 连接并读取。
3. 扫描探头，核对实物编码，选择粮温/仓温湿与测点编号。单支路无需填写编号。
4. 添加、更换、删除均先修改本地登记表，显示待新增/待修改/待删除；可撤销。
5. 点击“保存到分机”。程序检查分机版本、写入差异、核对暂存、保存、完整回读生效表，再同步电脑档案。
6. 关闭登记后开始采集。只采集已核对登记的实际点号，编号中间空号不会被当成探头。粮情详情可“采集当前分机一次”。

扫描顺序不代表安装位置。测温线、层和位置统一在粮情详情的“调整布点”维护；更换探头不删除该测点历史和布点。

## 等待为什么缩短

旧界面每次编辑往返读取 165 + 5 个槽位；现在编辑完全在本地完成。
V0.4 新增 `0x41/0x09` 按实际绑定分页，每页最多 20 条：空表 1 页、1 个探头 1 页、170 个探头 9 页。分页核对配置修订与总数，保存仍核对完整内容。

1200 波特率保持不变。每页及保存仍需要通信时间，满表传输不能瞬间完成。V0.3 可继续连接，新上位机会回退旧逐点读取；旧固件非空表仍较慢。获得完整加速需要同时更新上位机与分机 V0.4。

读取可以取消；写入及写后核对期间不能强行关闭。写入超时不自动重发，先只读核对实际结果；未证明保存成功不会显示成功。外部配置发生变化时要求重新读取，避免覆盖。

## 界面与数据保护

- 分机管理、串口设置、探头登记为独立页面；历史曲线和历史记录分别默认显示对应视图。
- 已打开串口、分机响应和有效测点分开显示；过期或断连读数变灰并标“上次读数”。
- 参数成功加载后才允许编辑，切换对象前提示未保存输入；采集/保存间隔明确为全局设置。
- 历史导出使用已应用的查询条件，并对最终文件名确认覆盖。
- 历史清理先预览，确认后暂停采集并复核数量；永久保存规则不变。
- 本地维护可导出通信诊断，包含本次运行的实际端口参数及最近收发摘要。时间是应用读写时间，不能据此判断线缆位时序。
- 电脑配置导入不会写入分机，也不会凭导入内容宣称分机已核验；需要重新读取登记表。

## 升级与现场验证

先用本地维护备份数据库，再完整解压新版上位机；无需清空历史。V0.4 保留原协议、Modbus、原 INFO/单点读取及配置存储格式，仍为 PB12 通信、PB13 低有效强上拉、PE2 供电配置开启、1200 / 8N1。

现场应依次验证：打开分机信息 → 扫描 → 登记 1 个探头 → 保存 → 关闭登记采集 → 重启读取绑定与历史 → 断开探头观察故障。编译、模拟器及自动化检查不能替代实际探头供电、测温精度和断电保存联调。
