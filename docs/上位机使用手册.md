# 利仓上位机快速使用手册

适用：上位机 0.1.5，配套分机 V0.5（兼容 V0.4）。

## 首次使用

1. **启动**：完整解压 Windows 包，运行 `WarehouseTemperatureConsole.exe`。首次选择语言后进入软件；以后可在「系统设置 → 语言设置」修改，重启生效。`Demo.cmd` 仅用于模拟演示。
2. **建仓房**：「仓房管理 → 仓房信息管理 → 新增仓房」。
3. **配串口**：「设备管理 → 串口设置 → 新增串口」，选择实际 COM 号，当前固件设为 **1200 / 8N1**。保存后点击「打开串口」。
4. **加分机**：「设备管理 → 测温分机管理 → 新增分机」，选仓房、串口，填写板上实际地址。一个串口可接多台分机，**同口地址不能重复**。
5. **登记探头**：选中分机 →「登记探头」→「扫描探头」→ 按实物位置选择探头编码、用途、测点编号 →「绑定」。当前只有一条支路，无需填写。
6. **保存并测温**：核对登记表 →「保存到分机」→ 等待保存、回读核对完成 →「关闭登记」→ 顶栏「开始采集」。

**注意：**绑定只修改本地草稿，必须保存到分机才生效。扫描顺序不代表安装位置。粮温编号 1～165，仓温仓湿编号 1～5；更换探头时，在原测点绑定新编码并保存。

## 日常操作

| 需要做什么 | 在哪里操作 |
| --- | --- |
| 查看温湿度和立体图 | 「数据管理 → 粮情详情」，选择分机 |
| 查看或导出历史 | 「数据管理 → 历史记录」，筛选后查询、导出 |
| 调整采集和保存间隔 | 「采集规则 → 测温分机采集规则」 |
| 设置温湿度偏移 | 「系统设置 → 温湿度微调」，只影响后续采集 |
| 设置阈值、查看和确认报警 | 「系统设置 → 报警记录」 |
| 备份数据库或清理历史 | 「系统设置 → 本地维护」；清理前先备份 |

数据保存在电脑本地，历史不会自动删除。电脑数据库与分机登记分别保存；备份现场配置时，也在登记页「高级选项」备份已保存登记。

## 常见问题

- **串口打不开**：检查 COM 号、驱动，关闭占用该串口的调试工具。
- **分机不响应**：核对接线、供电、1200 / 8N1 和板上地址；串口打开不代表分机在线。
- **扫描不到探头**：检查探头接线和供电，重新扫描；不使用失败扫描的部分结果。
- **绑定后无温度**：先确认已保存并核对，再确认正在采集；根据测点的离线、过期或故障提示排查。
- **保存结果不确定**：先重新读取分机，核对已保存登记，不要反复点击保存。

需要协助时，在「系统设置 → 本地维护 → 通信日志」导出通信诊断，并附上报错截图和分机地址。
