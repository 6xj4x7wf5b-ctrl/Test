# GXHT3W 探头编号工具

本工具在安装前给 GXHT3W 写入根号、点号。根号表示分组，室内/室外用途在采集软件中设置。

## 准备

- 使用已刷入 **GXHT3W_Numbering_Fixture** 固件的 STM32 编号工装。普通采集固件不支持本工具的写号操作。
- 电脑通过 USB 串口连接工装；探头接工装的单总线接口。PB12 为 DQ，PB13 低电平控制强上拉，按实际板供电接线。
- 一次只连接一只已确认型号为 GXHT3W 的探头。
- **首次使用先做空载检查**：外接插槽不插探头，点击读取应提示“工装未检测到探头”。现有硬件设计的板载 U16 与外接接口共用 DQ；若 U16 已焊接，需由硬件负责人提供未实装或已电气隔离 U16 的编号工装。空插槽仍读出 ROM 时禁止写入，以免误改板载探头。
- 关闭占用同一串口的采集软件、串口助手和其他编号窗口。

## 编一只探头

1. 打开工具，选择串口，连接工装。本版专用工装固定使用 **1200 / 8N1，地址 1**。
2. 选择或创建编号批次。**同一目标仓房/分机使用同一个批次**，便于发现重复编号。
3. 点击“读取探头”，查看当前编号。首次读取的数字可能是出厂值，不代表已编号。
4. 输入根号和点号（均为 **1～254**），点击“写入并校验”。软件会保留原配置字节，将编号保存到探头 EEPROM。
5. 看到“待断电复核”后，先点击“开始断电复核”。按提示完整拔下探头，等工具提示重新接入后，再插回同一只探头。当前等待至少 2 秒，现场仍需确认实际放电时间。
6. 显示完成后，在实物上贴上根号、点号标签，再更换下一只。开启自动递增时，完成后点号加 1；到 254 不回绕。

**关闭 PB13 强上拉、重启软件或复位 STM32，都不能代替探头真正断电。** 首次现场联调需确认拔插后的实际掉电与编号保持。

## 常见情况

| 提示或情况 | 操作 |
| --- | --- |
| 串口已打开，工装未就绪 | 核对地址、工装固件和连接；仅打开串口不代表工装握手成功 |
| 检测到多只探头 | 仅保留一只后重新读取 |
| 同批次编号重复 | 检查实物与编号记录，改用未占用的编号 |
| 写入中断、结果待核验 | 不要直接重写；重新连接，选择待核验记录，核对同一 ROM 并继续断电复核 |
| 暂时无法复核原探头 | 点击“稍后核验”，保留记录后给下一只编号；原 ROM 和目标编号继续占用，稍后从记录页恢复 |
| 同一只探头再次编号 | 使用明确的改号操作；软件不会把自动递增后的号码直接写回上一只 |
| 校验失败或数据变化 | 检查接线、供电和探头型号，重新读取；不要把失败记录当作已完成 |

编号记录保存在本机，可按批次查询并导出 CSV。不同电脑的清单不会自动同步；安装后仍需检查整条总线是否有重复根号、点号。

## 运行与保存

- **Windows**：解压完整运行包，运行 `GXHTProbeNumbering/GXHTProbeNumbering.exe`。保留同目录的依赖文件。
- **macOS 源码运行**：双击项目中的 `run_numbering_macos.command`；演示使用 `demo_numbering_macos.command`。
- **模拟演示**：顶部明确显示演示标识，可用模拟拔出、接入及下一只探头操作体验流程；演示数据库与实机编号记录分开，演示不访问真实串口。
- 数据保存在系统用户数据目录，也可用 `--data-dir` 指定独立目录。备份时关闭软件后复制该目录。

本版本提供编号工具与工装固件。日常采集软件按根号、点号自动匹配仓房的功能属于采集软件配套改造；不能把现有 ROM 登记表误认为探头内部编号。
